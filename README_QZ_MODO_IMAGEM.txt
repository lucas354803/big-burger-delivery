BIG BURGER - IMPRESSAO QZ EM MODO IMAGEM

Atualização aplicada:
- A impressão automática pelo QZ Tray agora envia a comanda como IMAGEM/PIXEL.
- Isso evita aparecer ????? quando o nome do produto tem emoji, estrela, acento ou caractere especial.
- Mantém logo, QR Code e layout visual.

Como usar:
1. Suba este ZIP na Vercel.
2. Abra o QZ Tray no computador da loja.
3. Entre no Admin > Impressora.
4. Mantenha marcado: Usar QZ Tray para imprimir 100% automático.
5. Clique em Salvar configuração.
6. Faça um pedido teste e aceite o pedido.

Observação:
Se a impressão sair muito grande ou cortada, ajuste o papel na aba Impressora:
- Bobina 80mm para impressora 80mm
- Bobina 58mm para impressora 58mm
