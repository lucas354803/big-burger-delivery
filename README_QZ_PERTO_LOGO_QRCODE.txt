BIG BURGER - QZ PERTO Printer TEC / LOGO + QR CODE

Este ZIP foi ajustado para:
- Remover emojis/caracteres que viravam ????? na comanda.
- Imprimir em modo RAW seguro para PERTO Printer TEC.
- Tentar imprimir a logo antes da comanda via QZ imagem ESC/POS.
- Imprimir QR Code nativo ESC/POS do pedido/motoboy.
- Se a logo ou QR falhar, o sistema cai para texto seguro e não trava o pedido.

IMPORTANTE SOBRE O AVISO DO QZ:
O aviso de certificado não é removido só pelo site. Ele depende do QZ Tray instalado no Windows.
Para reduzir/remover o aviso:
1. Feche o QZ Tray perto do relógio.
2. Execute: CONFIGURAR_QZ_SEM_AVISO_E_REINICIAR.bat
3. Abra o QZ Tray como administrador.
4. No primeiro aviso, marque Remember this decision e clique Allow.

Se o botão Allow ainda ficar cinza, o QZ está recusando certificado não assinado. A solução 100% definitiva é certificado assinado QZ.
Para uso na loja, o método acima normalmente resolve.
