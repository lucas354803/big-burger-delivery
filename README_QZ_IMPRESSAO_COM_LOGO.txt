BIG BURGER - IMPRESSÃO AUTOMÁTICA QZ COM LOGO

O que foi ajustado:
- QZ Tray agora tenta imprimir a comanda em HTML bonito.
- Usa logo /print-logo.png.
- Usa QR Code do pedido/motoboy.
- Mantém impressão automática sem abrir a tela do navegador.
- Se a impressão HTML falhar em alguma impressora, o sistema cai automaticamente para o modo texto térmico para não parar os pedidos.

Passo a passo:
1. Suba este ZIP na Vercel.
2. Deixe o QZ Tray aberto no Windows.
3. No Admin, vá em Impressora.
4. Marque: Usar QZ Tray para imprimir 100% automático.
5. Clique em Testar QZ.
6. Clique em Allow e marque Remember this decision.
7. Clique em Carregar impressoras QZ.
8. Escolha sua impressora térmica ou deixe Impressora padrão do Windows.
9. Clique em Salvar configuração.
10. Clique em Testar impressão.

Observação:
- Para logo sair, o arquivo print-logo.png precisa estar no projeto. Ele já está incluído.
- Se sair muito grande/pequeno, ajuste Tamanho do papel, Tamanho da letra e Margem na aba Impressora.
