IMPRESSÃO 100% AUTOMÁTICA COM QZ TRAY - BIG BURGER

1) Instale o QZ Tray:
   https://qz.io/download

2) Abra o QZ Tray no Windows.
   Ele precisa ficar aberto perto do relógio.

3) Suba este ZIP atualizado na Vercel.

4) No Admin Big Burger, entre em:
   Impressora

5) Clique em:
   Testar QZ

6) Na janela do QZ Tray, clique em:
   Allow / Permitir
   e marque a opção para lembrar/permissão sempre.

7) Clique em:
   Carregar impressoras QZ

8) Escolha sua impressora térmica ou deixe como Impressora padrão do Windows.

9) Marque:
   Usar QZ Tray para imprimir 100% automático
   Imprimir automaticamente ao aceitar pedido

10) Clique em:
   Salvar configuração

11) Clique em:
   Testar impressão

OBSERVAÇÃO IMPORTANTE:
- Para impressão automática real sem tela, o QZ Tray é obrigatório.
- O QZ precisa ficar aberto no computador da loja.
- A primeira conexão pode pedir permissão. Marque Permitir sempre.
- A impressão QZ envia texto térmico direto para a impressora.
