ATUALIZAÇÃO: ABA BANNER / VÍDEO

O que foi adicionado:
- Nova aba no Admin: 🎬 Banner / Vídeo
- Você pode trocar a imagem/vídeo grande da página inicial
- Aceita vídeo MP4 por link ou imagem por link
- Edita título, texto, botão, selo e ativa/desativa o banner

IMPORTANTE NO SUPABASE:
1. Abra o Supabase do projeto
2. Vá em SQL Editor
3. Cole e execute o arquivo: supabase/site_banner.sql
4. Depois publique/substitua os arquivos no Vercel

Como usar:
Admin > Banner / Vídeo > edite os campos > Salvar banner.
No campo URL da mídia você pode usar:
- /bigburger-video.mp4
- https://site.com/video.mp4
- https://site.com/imagem.png
